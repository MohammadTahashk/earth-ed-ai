## 🐛 If Something Goes Wrong

### Port Already in Use
```bash
# Try a different port
npm run dev -- --port 3000
```

### Module Errors
```bash
# Reinstall dependencies
rm -rf node_modules package-lock.json
npm install
```

### Build Errors
```bash
# Clean and rebuild
rm -rf dist
npm run build
```
